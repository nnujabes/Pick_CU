# GGUF 양자화 (A.X, EXAONE)

파인튜닝 어댑터를 원본 모델에 합친 뒤 Q5_K_M으로 양자화한 재현 코드와 평가 결과입니다.

**최종 모델은 A.X 4.0 Light입니다.** EXAONE은 비교용으로만 양자화했으며 웹에는 연결하지 않습니다.
dev와 test를 합친 456문장에서 두 모델의 차이는 1%p 이내로 통계적으로 뚜렷하지 않아, 이미 웹에 연결해 검증한 A.X를 유지했습니다.

## 팀원은 모델을 받지 않아도 됩니다

- 모델 파일은 `ax-4.0-light/`에 두지만 용량 때문에 git에는 올라가지 않으며, 시연은 혁준 PC에서 실행합니다.
- 모델이 없는 PC에서 `npm start`를 실행하면 규칙 파서로 동작합니다.
- 이 폴더는 기존 `members/jongho/fastapi` 실행 방법을 바꾸지 않습니다.
